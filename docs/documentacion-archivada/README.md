# Documentación archivada

Estas son versiones históricas de la documentación de Barbería Cale. **Ya no representan el estado actual completo del sistema y no deben utilizarse como especificación vigente, guía de instalación actual ni evidencia de funcionalidades recién verificadas.**

Archivo organizado el 3 de octubre de 2026. Se preservan los originales y su estructura de rutas para consultar la evolución del proyecto. No se eliminaron sus contenidos. El nombre «actual» o «versión final» dentro de un archivo describe el momento en que se redactó, no su vigencia presente.

## Documentos y motivo del archivo

| Ubicación dentro de esta carpeta | Motivo |
| --- | --- |
| `CAMBIOS_VERSION_FINAL.md` | Comparación de revisiones antiguas; todavía presenta la integración de WhatsApp como pendiente de commit. |
| `proyecto/docs/alcance-v1.md` | Alcance anterior a dispositivos push, recordatorios y confirmación de asistencia. |
| `proyecto/docs/requisitos-v1.md` | Línea base RF-01 a RF-17; su definición de historial no incluye citas vencidas pendientes de cierre. |
| `proyecto/docs/trazabilidad-v1.xlsx` | Matriz limitada a RF-01 a RF-17 y a los contratos de esa versión. |
| `proyecto/docs/arquitectura-v1.pdf` y `.png` | Arquitectura inicial; no documenta el subsistema actual completo de recordatorios y trabajos persistentes. |
| `proyecto/docs/Documento consolidado de avance Barberia_Cale.pdf` | Entrega Avance 1 con alcance y requisitos v1. |
| `proyecto/prototipo/prototipo-v1.pdf` | Lámina inicial de pantallas, anterior al banco de capturas de ejecución del segundo parcial. |
| `proyecto/docs/arquitectura-actual/` | Snapshot con corte declarado del 27 de agosto: MD, HTML, PDF y generadores. Contiene definiciones desactualizadas de disponibilidad/historial y referencias a la línea base v1. |

El snapshot de arquitectura incluye copias de sus diagramas y fuentes para que el HTML y el Markdown históricos mantengan sus imágenes y enlaces. Esas copias son recursos del archivo; las fuentes mantenidas se encuentran en la carpeta vigente.
